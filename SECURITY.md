# Reporting Security Issues

To report a vulnerability, please contact us via [code@jackyd.com](mailto:code@jackyd.com?subject=Flowseer%20-%20Security%20Report&body=Description%20of%20the%20vulnerability%3A%0A%0A%0ASteps%20to%20reproduce%3A%0A1.%20%0A2.%20%0A3.%20%0A%0AImpact%20of%20the%20vulnerability%3A%0A%0A%0AAffected%20version(s)%3A%0A%0A%0AOperating%20system%20and%20environment%3A%0A%0A%0AAdditional%20information%20or%20attachments%3A%0A).

We recommend that you use the latest versions of the cli to ensure that your application remains as secure as possible.
