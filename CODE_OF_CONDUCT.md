# Code of Conduct

As maintainers of this project, we are committed to fostering a welcoming, respectful, and inclusive environment for anyone who interacts with the project—whether by contributing code, reporting issues, giving feedback, or using the software.

While this is currently a small team, we aim to set clear expectations and maintain a healthy standard of conduct from the start.

## Expected Behavior

All interactions in this project should be:

- Respectful, constructive, and considerate  
- Free from personal attacks, discrimination, or exclusion  
- Focused on collaboration and technical improvement  
- Open to feedback and differing perspectives

## Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment, threats, or abusive language  
- Discrimination based on personal characteristics  
- Trolling, spamming, or intentionally disruptive behavior  
- Sharing offensive content or engaging in hostile interactions

## Enforcement

As maintainers, we reserve the right to take appropriate action in response to any behavior that violates this code—including removing comments, blocking contributors, or reporting abuse.

For any concerns or questions related to this Code of Conduct, feel free to reach out directly via GitHub or the contact methods listed in the repository.
